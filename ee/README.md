# ee — enterprise edition

Enterprise-edition modules live here, behind a clean interface boundary, so the open-source core builds, tests and runs without this directory (`GOV-033`). Production use of code in this directory will require a commercial license; security capabilities are never placed here (`GOV-032`).

The directory is empty until **P9**. The licensing model is recorded in [ADR-0022](../docs/adr/0022-open-core-licensing.md).
