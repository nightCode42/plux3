# Security Policy

Plux is designed for high-assurance use (see `docs/requirements.md` §15). We take every report seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report privately through
[GitHub Security Advisories](https://github.com/nightCode42/plux3/security/advisories/new).

Include the affected component and version, steps to reproduce, and the impact you observed.

## Response targets (`SEC-192`)

| Step | Target |
|---|---|
| Acknowledge the report | 3 working days |
| Initial assessment and severity | 7 working days |
| Fix or mitigation for critical and high issues | 30 days |
| Coordinated public disclosure | After a fix is released, or 90 days after the report |

## Supported versions

Until 1.0, only the latest commit on `main` receives security fixes.
