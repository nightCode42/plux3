### M5 — design decisions (drafted 2026-09-26, not yet implemented)

Drafted with ADR-0009 and Appendix E; implement as written unless a test shows a problem, and record each in `docs/reference/pxl.md`.

- **Values.** `int` 64-bit (overflow and ÷0 are typed errors); `double` IEEE, NaN or ±∞ results are the error `nonFinite`; `decimal` exact, keeps its scale ("12.50"), compares numerically; `money` = decimal + ISO 4217 code, `+`/`-`/compare need the same currency, `money × decimal` allowed, no `/` (use `div`); strings are code-point sequences; `date` = days since 1970-01-01 (years 1–9999); `dateTime` = epoch milliseconds + UTC offset in minutes, equal and ordered by instant; `duration` = milliseconds; `color` RGBA; enums, `asset` and `route` are strings at run time; objects and maps are string-keyed maps iterated in code-point key order.
- **Typing.** No dynamic type; `null` and the empty list/map have internal `Null`/`Never` types; `int` widens to `double` and `decimal` only at the expression level (the checker inserts `INT_TO_DOUBLE`/`INT_TO_DEC`), never inside collections; enums accept string literals naming a member; `a.b` on a nullable value is `PLX-2006`; built-in enums `RoundingMode` (`halfEven` default, `halfUp`, `down`, `up`, `ceiling`, `floor`) and `DateStyle`; `int / int` truncates, `%` is the truncated remainder; decimal `/` is `PLX-2007` with the `div` fix.
- **Bytecode** (single source `schema/pxl/bytecode.json`, generated for Go and Dart). Program v1: version, locals count, max stack, result type as a type expression, constant pool (tagged, deduplicated, first-use order), read set, code; counts and lengths as unsigned LEB128, operands fixed-width little-endian, jumps as u32 absolute offsets. Typed opcodes: stack and constants, `LOAD_ROOT`, `LOAD_LOCAL`, `GET_FIELD` (absent object field → null), `MAP_GET`/`INDEX_MAP` (absent key → `missingKey`), `INDEX_LIST`, jumps including keep-on-condition forms for `&&`, `||`, `?.` and `??`, arithmetic per type (`ADD_INT`, `ADD_DEC`, `ADD_MONEY`, `MUL_MONEY_DEC`, `ADD_DT_DUR`, …), `CONCAT_STRING`/`CONCAT_LIST`, `EQ`/`NE` (deep), `CMP_<type>` then `LT`/`LE`/`GT`/`GE`, `IN_LIST`/`IN_MAP`, `NEW_LIST`/`NEW_MAP`/`LIST_APPEND`, `CALL id argc`, and `ITER_INIT`/`ITER_NEXT`/`ITER_LIST`/`SORT_BY kind` for the macros `map`, `filter`, `any`, `all`, `sortBy`. The M7 `pxl` section stores the encoded program; its ID is the first 8 bytes of SHA-256 of the encoding (ADR-0002).
- **Cost model** (identical in Go and Dart): 1 per executed instruction; `CALL` adds the size of each string, list or map argument and of the result (code points or elements); `CONCAT_*` add the result size; `NEW_LIST`/`NEW_MAP` add the element count; `EQ`/`NE`/`IN_LIST` add the nested values visited; `SORT_BY` adds n·⌈log₂(n+1)⌉. Budget from `pxl.operationBudget`; result sizes bounded by `pxl.stringLength`, `pxl.collectionSize` and a new key `pxl.decimalDigits` (see open decisions).
- **Run-time error kinds:** `budgetExceeded`, `overflow`, `divisionByZero`, `nonFinite`, `currencyMismatch`, `unknownCurrency`, `indexOutOfRange`, `missingKey`, `invalidArgument`, `sizeLimit`, `duplicateKey`, `unsupported` (a later-phase group), `invalidProgram`, `invalidInput`. Folding maps them to `PLX-2010`/`PLX-2011`.
- **Standard library** (`schema/pxl/stdlib.json`): one permanent ID per overload (~150), groups with features — `core` (`pxl.v1`, P1), `format` and `l10n` and `calendar` (P8), `phone` and `regex` (P5); `format.iban` is core. Rules: rounding defaults to half-even everywhere (also `round(double)`, which returns `int`); `upper`/`lower` use simple case mapping and `trim` the Unicode White_Space set, both from Go's `unicode` tables; `replace` with an empty pattern returns the input; `substring`/`slice` reject out-of-range indices while `at`/`first`/`last` return null; `keys` sorts by code point; `distinct` only on scalars, keeping first occurrences; `sum([])` is 0; `string(double)` is the ES6 algorithm (`jcs.FormatNumber`); `decimal(double)` is the shortest round-trip form; `isIban` ignores spaces and checks structure and mod 97 (not per-country lengths); `isEmail` is an ASCII rule set (local part ≤ 64, labels ≤ 63, ≥ 2 labels, alphabetic TLD, total ≤ 254); `coalesce`, `ifNull`, `isNull` are expanded inline and `typeOf` is a compile-time constant.
- **Currencies** (`schema/pxl/currencies.json`): ISO 4217 list one, 164 active codes with numeric minor units; funds and metals without minor units excluded, and the retired `ANG`, `BGN`, `CUC`, `HRK`, `SLL`, `ZWL`. Non-2 minor units: 0 — BIF CLP DJF GNF ISK JPY KMF KRW PYG RWF UGX UYI VND VUV XAF XOF XPF; 3 — BHD IQD JOD KWD LYD OMR TND; 4 — CLF UYW. Cross-checked against CLDR (`golang.org/x/text/currency` in the module cache): the only differences are CLDR's known "practice" digits (AFN, ALL, AMD, COP, GYD, IDR, IQD, IRR, KPW, LAK, LBP, MGA, MMK, MNT, MUR, PKR, RSD, SOS, SYP, TZS, UZS, YER), and MRU, SLE, UYW, VED, VES, XCG, ZWG are newer than that CLDR version. The SIX list could not be downloaded here (proxy 403); verify against it before P1 closes.
- **Conformance vectors** (`schema/testdata/pxl/<topic>.json`): an environment (`types` with enums and objects, `roots` as type expressions), then cases with `expr`, `inputs` (JSON per the literal table of `document-model.md` §3, `now` as RFC 3339), and one of `value`, `error` (kind) or `diagnostics` (code and code-point range), plus the goldens `type`, `program` (base64), `asm` and `reads`. The Dart VM runs `program` against `inputs` without a compiler.
